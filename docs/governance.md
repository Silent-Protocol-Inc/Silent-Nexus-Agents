# Governance

Silent Protocol maintains Silent Nexus under the Apache-2.0 license.

Decisions prioritize, in order:

1. operator security and data integrity;
2. honest reporting and reproducible evidence;
3. 1.x compatibility;
4. reliability and maintainability;
5. convenience and additional autonomy.

Changes to policy, approval, isolation, credentials, Git execution, storage,
migrations, release tooling, or compatibility require adversarial tests and
documentation. No single model assertion is accepted as release evidence.

Maintainers may close a security bypass even when doing so narrows an existing
workflow. Material security breaks are documented in the changelog and upgrade
guide.

Release artifacts are certified only for targets with completed evidence. A
workflow file or successful compilation alone does not certify a platform.

Contribution and review expectations are defined in
[`../CONTRIBUTING.md`](../CONTRIBUTING.md) and repository
[`../AGENTS.md`](../AGENTS.md).
