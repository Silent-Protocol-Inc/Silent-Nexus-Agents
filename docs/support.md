# Support

For non-security defects, use the repository bug template and include:

- `snx --version` and `snx about`;
- certified/experimental platform;
- minimal reproduction;
- redacted `snx doctor --deep` and relevant audit/log output;
- whether container or approval-only host execution was active.

For usage questions, consult the README, CLI reference, operator guide, and
troubleshooting guide first.

Do not post secrets, auth profiles, private provider payloads, `.nexus` state,
or unredacted logs publicly.

Security vulnerabilities must use the
[private vulnerability reporting channel](https://github.com/Silent-Protocol-Inc/Silent-Nexus-Agents/security/advisories/new),
not a public issue.
